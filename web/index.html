      ボード

      設定

      外観

      DuoTone（simurai、MIT）を基にした4配色です。

      AI API設定

      利用者のブラウザから提供元へ直接送信します。弊社のサーバーへキー・会話は送りません。

      詳細設定

      AIへの接続方式です。候補モデルを選ぶと自動設定されます。

      Responses：OpenAIの新しい接続方式。

      Chat Completions：OpenAIの従来の接続方式。

      Messages：Claudeの接続方式。

      Generate Content：Geminiの接続方式。

      モデルが対応する方式を使う必要があります。

      保存先はこのブラウザです。暗号化保管ではありません。「保存せず使う」はこのページだけに反映します。閉じるだけなら編集を破棄します。

      「既定にする」は、いま表示している提供元とモデルを次回の起動時に開く設定として保存します。キーは保存しません。

      ヘルプ

      1. 「ボード」でボードを選び、main.cpp を編集して「Build」を押す
      2. 「書き込み」でボードへ書き込み、「シリアル」タブで出力を見る

      対応ボード：

      ブラウザ：Chrome / Edge（Web Serial と File System Access を使います）

      保存先はこのブラウザ内です。同期・バックアップではありません。エクスプローラの「ファイル」→「ファイルへ書き出す」で zip にして持ち出せます。

      使い方は右の AI に聞けます（API キーが必要）。

      広告
      このブラウザに自動保存：読み込み中… ↓ UF2 ダウンロード

      エディタを読み込み中…

      Build → 書き込み → シリアルで確認。困ったら右の AI へ
